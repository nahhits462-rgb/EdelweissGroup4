Demonstrating the Box Model

The CSS box model is essentially a box that wraps around every HTML element. It consists of: borders, padding, margins, and the actual content.

This text is the content of the box. We have added a 10px padding, 10px margin and a 15px green border.
This box contains an additional 320px Width and 60px Height. It also have a 10px padding, 10px margin and a 15px grey border.

The display Property

display: inline

This example will align the box within the paragraph. Content1 Content2 and will continue with the text inline with it.

This example however, will align the box on the paragraph and will continue to expand up to the end of the screen. But the continuation of text will be on the next line of the box.
